# Expense Tracker v7 — полный сайт для GitHub/Render

Содержимое архива загружается прямо в корень репозитория. Папки templates/static
сохраняйте. Архив не содержит базы, ключей и виртуального окружения.

## Render (существующий сервис)
Environment: DATABASE_URL — строка Supabase Connect → Session pooler с настоящим
паролем (пароль URL-кодировать при необходимости). Не публикуйте её.
SECRET_KEY — случайная строка минимум 32 символа, сохранять неизменной.
Build Command: pip install -r requirements.txt
Start Command: gunicorn app:app --bind 0.0.0.0:$PORT
Root Directory: пусто (app.py в корне).
Нажмите Save, затем Manual Deploy → Deploy latest commit.
render.yaml применяется при создании Blueprint, не заменяет ручную настройку
Environment уже созданного сервиса.

## Данные
Supabase, схема tracker_v6 (совместима с v6). Старые public-таблицы не удаляются,
но автоматически не переносятся. Для этой схемы зарегистрируйтесь заново,
если ещё не регистрировались в v6. Демо-данных нет. Пароль минимум 8 символов.
Пользователи видят только свои расходы.

## Автовход
Подписанная cookie до года; это браузер, а НЕ привязка к железу. Очистка cookies,
смена SECRET_KEY и выход прекращают сессию. На общем устройстве выходите.
Ограничить физическое устройство одним человеком обычный сайт не может.

## Локально
Python 3.10+: python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
В PowerShell: $env:DATABASE_URL="ваша строка"; $env:SECRET_KEY="случайная строка"
.venv/Scripts/python.exe app.py
Браузер: http://127.0.0.1:5000

## Безопасность
Пароли хешируются, SQL параметризован, формы защищены CSRF. Не выставляйте схему
tracker_v6 через публичный Supabase Data API; сервер подключается по DATABASE_URL.
Для массового публичного использования дополнительно нужны ограничения попыток
входа, мониторинг и резервное копирование. Бесплатные планы имеют ограничения.
